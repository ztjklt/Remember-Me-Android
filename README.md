2026-10-19，仓库所有者将两个仓库整合为一个公开展示与开发入口。本库截至 `67eab91` 的独立提交历史、独有来源材料及有效测试修正已保留在统一仓库；新版 Android 0.16.8 与配套服务在统一仓库的 `main`。本库保留为只读归档，旧提交与来源可以继续浏览。

已有本地副本可在保存自己的未提交改动后更换远程：

```sh
git remote set-url origin https://github.com/ztjklt/Remember-Me.git
git fetch origin
git switch main
git pull --ff-only origin main
```

统一主线包含本库原 `main` 的祖先历史，因此原 `main` 没有个人分叉时可快进。保留自己的功能分支和未提交内容；有分叉时先检查差异。

Consolidated into **[ztjklt/Remember-Me](https://github.com/ztjklt/Remember-Me)**. The former Android history and unique handoff documents are preserved there. Please use the unified repository for source, documentation and further development.
